What the plugin does

A Dev Mode-style inspector plus the handoff workflow Figma does not ship. Every feature runs inside Figma — the plugin code makes no network requests at all.

Inspect

Dev Mode-style specs

Box model, Auto Layout, typography, fills, strokes, effects, variables in every mode, component properties and overrides, dev resources and interactions.

Design to code

12 code targets

React + TypeScript, React + Tailwind, React + CSS, HTML + CSS, single-file HTML, Vue, Svelte, React Native, SwiftUI, Jetpack Compose and Flutter — with typed props, design tokens and a project ZIP.

Handoff

Ready for dev gate

Designers mark a frame ready; only then do specs, code and assets unlock. Turn the gate off and DevReady is simply a free Figma inspector and code generator.

Tokens

Design token export

Export one layer or a whole file as CSS variables, SCSS, design-tokens JSON or a Tailwind v4 @theme block, including every variable mode.

Accessibility

WCAG 2.2 checks

Contrast for every text layer, touch-target sizes, unlabelled icon buttons and text under 12px. Click a finding to select the layer.

Change tracking

Before → after

See which layers changed since handoff — size, position, style, text, added and removed — with the old and new values side by side.

Install the Figma plugin in 2 minutes

DevReady is a local development plugin — it is not on Figma Community yet. You need the Figma desktop app.

  1. Clone or download the repository: git clone https://github.com/Ankushui18/Dev-Ready.git
  2. In Figma: Plugins → Development → Import plugin from manifest… and choose devready-plugin/manifest.json.
  3. Open any file and run Plugins → Development → DevReady Inspect. In Dev Mode (Shift+D) it lives under Inspect → Plugins, and its codegen languages appear in Inspect → Code.
  4. No Figma file handy? Open devready-plugin/ui.html in a browser — the panel runs on sample data.

The first run shows a lock: that is the ready-for-dev gate. Select a frame and choose Mark as ready for dev, or Inspect anyway to look around.

Frequently asked questions

Short answers for people searching for a free Figma Dev Mode plugin, a Figma inspect panel or a Figma-to-code tool.

Is DevReady a free Figma Dev Mode alternative?

Yes. DevReady Inspect is a free Figma plugin with a Dev Mode-style Inspect panel for sizes, spacing, typography, fills, variables, component properties and assets. It also adds a Ready for dev gate, change tracking, WCAG 2.2 accessibility checks, design token export and code generation in 12 targets. It cannot replace Dev Mode features that Figma does not expose to plugins, such as hover-to-measure on canvas, version comparison and notifications.

Do I need a paid Figma Dev Mode seat to use it?

No. DevReady runs on a free or Starter Figma plan, in Design mode and in Dev Mode. Where Figma's native Ready for dev status or annotations are unavailable, the plugin uses its own flag and canvas notes and labels which one it used.

What code can DevReady generate from a Figma design?

Twelve targets: React + TypeScript, React + TypeScript + Tailwind, React + Tailwind, React + CSS, HTML + CSS, single-file HTML, Vue, Svelte, React Native, SwiftUI, Jetpack Compose and Flutter. Output includes semantic tags, design tokens, typed props and a downloadable project ZIP with assets and fonts.

How do I install the DevReady Figma plugin?

Clone or download the GitHub repository, then in the Figma desktop app use Plugins → Development → Import plugin from manifest and pick devready-plugin/manifest.json. Run it from Plugins → Development → DevReady Inspect, or in Dev Mode from Inspect → Plugins. Everything runs inside Figma: no account, no server, no tracking.

Does the plugin send my designs anywhere?

No. The plugin code makes no network requests; fonts are matched against a bundled catalog of 1,950 public Google Fonts. The only optional traffic is the HTML preview loading public Google Fonts, which you can switch off. See PRIVACY.md.
